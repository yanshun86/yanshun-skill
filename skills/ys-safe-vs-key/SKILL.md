# 安全动作 vs 关键动作

> **做了所有"看起来对"的事，没做那件"唯一能让事情发生变化"的事。**

## 两个定义

| | 定义 | 例子 |
|:--|:--|:--|
| **安全动作** | 做了**不会**被拒绝的事 | 发内容、调封面、看数据、学新工具、优化方案、整理素材 |
| **关键动作** | 做了**可能**被拒绝、但必须做的事 | 诊断完报价、主动约谈、问"你要付费吗"、开口要钱 |

**区别不在"哪个更对"——在于你敢不敢让对话走向交易。**

## 识别方法

问一句：

> **你现在花时间最多的那件事——它是"可能会被拒绝"，还是"几乎不会被拒绝"？**

答案是后者，你很可能在用安全动作回避关键动作。

## 怎么执行

1. **先要一份动作清单。** 让对方列出最近两周花时间最多的 5 件事，以及各自大致占比。没有清单就下判断，会变成互相猜。
2. **逐条归类。** 每一条问："做这件事，有可能被对方拒绝吗？" 当场标成 安全 / 关键。
3. **算比例。** 安全动作占比超过 80%，结论几乎固定。
4. **找出那个被回避的具体动作。** 不要停在"你该多做关键动作"——要指名："你回避的是报价"、"你回避的是给某人打电话"。
5. **给一个今天就能做的、最小的关键动作。** 不是"以后要多报价"，是"今天给某个人发一句话"。

## 真实案例（作者自己的）

公众号文章《我花了 100 个小时赚了 0 元》就是这张卡的来源。

100 小时全部投在安全动作上：写内容、做封面、看数据、学工具。**关键动作一次都没做。**

后来对照：4 个月、100 条视频、17 篇长文，**主动报价 0 次**。

## 反例 / 边界

**不是所有安全动作都没用。**

内容本身是安全动作，但它有价值。**只有当"只做内容、不做转化"时才是问题。**

判断标准只有一个：**这些安全动作，有没有通向某一个具体的关键动作？** 有，就是正常的准备；没有，就是回避。

另外：有些阶段关键动作确实做不了（比如产品还不存在）。这时要说清楚"现在是该造东西的阶段，不是该卖的阶段"，不要硬套这张卡。

## 输出

给结论时用一句话收口：

> 你这两周 xx% 的时间花在不会被拒绝的事上。你回避的那个动作是 ______。今天能做的最小版本是 ______。
