# 止损判断三问

> **不是该不该扛——是该不该继续用现在这种扛法。**

## 为什么成立

创业者最怕的不是做错决定，是错了一直不认。

但"止损"不是"放弃"，是**停止用一种已经证明无效的方式继续**。

三问帮你区分：我是在坚持，还是在重复错误？

## 三问

1. 我现在继续投入，是因为**有新的积极信号**出现，还是因为**不甘心之前的投入**？
2. **如果换一个人**在我这个位置，他会继续还是会停？
3. 从现在往回看，**三个月前的投入决定是对的吗**？

## 怎么执行

**一次问一问，不要三问同时抛出。** 每问完一个，等对方回答，再做下一个。

- 第 1 问要追问到底：**具体是什么新信号？什么时候出现的？它能被验证吗？** 如果对方说不上来具体信号，答案通常已经出来了。
- 第 2 问要卡住那个最顺口的借口："换一个人没我了解这摊事"——这不是理由，这是沉没成本在说话。可用变体："一个刚接手、没有历史包袱的职业经理人会怎么做？"
- 第 3 问最容易得到诚实答案。如果对方说"当时是对的，现在情况变了"，接着问："变了的是外部条件，还是你一直不愿意承认的那件事？"

三问答完后给一个判断，不要模棱两可。判断要指向动作："继续，但设一个明确的验证点" / "停" / "再用 X 周验证一件事，验证不成立就停"。

## 真实案例（作者自己的）

公司负债 3300 万时，创始人让我转 4000 块。

那 4000 块不是钱的问题——是我**明知道公司在走向死亡，还在用一个"兄弟情谊"的理由继续往里填**。

当时如果问自己三问，可能早就看清了。

## 反例 / 边界

**创业早期亏损不等于需要止损。**

区分标准：亏损是在"**投入期**"（有可预期的回报路径）还是在"**消耗期**"（看不到出口，只是不想承认）。

如果对方拿不出任何"投入期"的证据，那就是消耗期。

## 用法

可以直接把三问交给用户自己对照，也可以由你逐问引导。引导时不替对方回答。
