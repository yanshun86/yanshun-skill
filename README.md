# yanshun-skill

简体中文 · [English](README.en.md)

言顺的经营判断工具箱。三个判断卡，可安装到支持 Skills 的 Agent 中使用。

作者：言顺 · GitHub [@yanshun86](https://github.com/yanshun86) · X [@GYanshun53764](https://x.com/GYanshun53764)

---

## 这是什么

三个判断，来自一线的操盘和亏损，不是理论：

- 三年 358 单、644 万回款、峰值 40 人，**亏掉约 100 万**
- 3 个人、8 个月、**300 万以上毛利**，无应收款
- 0 → 2.5 亿 GMV，然后提前 316 天识别风险，**被欠薪 88,491 元**

这些卡是踩过之后留下的对照表。它们只做一件事：

> **把"我感觉不对劲"，变成"我知道该问哪三个问题"。**

---

## 三个判断

| 你现在的处境 | 用哪个 |
|:--|:--|
| 这个项目、这段投入，还要不要继续 | `/ys-stop-loss` · 止损判断三问 |
| 一直在做，做了很多，就是没结果 | `/ys-safe-vs-key` · 安全动作 vs 关键动作 |
| 有业务有订单，账上却越来越紧 | `/ys-cashflow-signals` · 现金流断裂前的中早期信号 |

不知道用哪个，直接输入 `/ys`，把情况说出来。

---

## 安装

终端需要能运行 `npx`。

```bash
npx -y skills add yanshun86/yanshun-skill -g --all
```

只想装到某一个 Agent 时，去掉 `--all`，按提示选择。

安装后在 Agent 对话里输入：

```
/ys
```

---

## 怎么用

直接说你的情况，不用先选工具。

判断需要具体事实：**持续多久、亏了多少、发生了什么信号、谁在做什么**。

信息不够时，只会问你一个最影响判断的问题——不会给你一张问卷。

---

## 边界

这三个工具只做**判断**：

- 要不要继续
- 卡在哪一步
- 到哪个阶段了

**不做**执行方案：商业计划书、定价方案、增长策略、财务测算。

超出范围的请求会直接说明，不硬答。
